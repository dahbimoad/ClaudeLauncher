**The project list re-sorts the moment you open a project.**

### Changed

- Projects are ordered by how many times you open them, with pinned projects always on top. The list now updates straight after each launch instead of waiting until the window is focused again.

### Fixed

- When the launcher was started from inside a Claude Code session, new tabs were treated as child sessions and didn't save transcripts. The inherited session variables are now cleared before each launch. Variables you set yourself (User or Machine scope) are kept.

### Install

Download `ClaudeLauncher-win-Setup.exe` below and run it. Installed copies update themselves on their next launch.

Needs Windows Terminal and Claude Code (`claude`) installed.
