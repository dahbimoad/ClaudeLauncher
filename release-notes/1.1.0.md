**Open Claude Code in any project folder in one keystroke.**

### What it does

- Lists every folder in `Desktop\projects`, most used on top.
- Type a few letters, press **Enter**: Claude starts in that folder in a new Windows Terminal tab.
- All sessions share one terminal window as tabs. **Ctrl+Enter** or **New window** opens a separate one.
- **Pin** favorites to keep them at the top (**Ctrl+P** or the pin on the row).
- **Add folder** adds any folder on your PC, not only the ones in `Desktop\projects`.
- Right-click a project to open it in Explorer, pin it, or remove an added folder.

### Automatic updates

From this version on, Claude Launcher checks GitHub when it starts and downloads new releases in the background. A bar tells you when one is ready: press **Restart now**, or just close the app and it installs quietly.

### Install

Download `ClaudeLauncher-win-Setup.exe` below and run it. It installs for your user only, with no administrator prompt, and adds Desktop and Start Menu shortcuts. Windows SmartScreen warns once on an unsigned installer: **More info > Run anyway**.

Needs Windows Terminal, PowerShell 7 (`pwsh`) and Claude Code (`claude`) installed.
