**The installer no longer installs anything else: the .NET runtime now ships inside the app.**

### Changed

- Claude Launcher is now self-contained. Setup.exe no longer downloads and installs the .NET 10 Desktop Runtime first; the app runs on a fresh Windows 10/11 PC as soon as it is installed.
- Faster startup (ReadyToRun compiled).

### Install

Download `ClaudeLauncher-win-Setup.exe` below and run it. Installed copies update themselves on their next launch.

Needs Windows Terminal and Claude Code (`claude`) installed.
