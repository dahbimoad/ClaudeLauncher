**Fix: "Open Claude" failed with error 0x80070002 on PCs without PowerShell 7.**

### Fixed

- The launcher no longer requires PowerShell 7 (`pwsh`). It uses `pwsh` when it is installed, otherwise the Windows PowerShell built into every Windows 10/11.
- **Enter** now opens the new tab in the Windows Terminal window you already have open, instead of a separate launcher window. **Ctrl+Enter** or **New window** still opens a new window.
- If the terminal cannot start, the launcher stays open instead of crashing.

### New

- Every launch is logged to `%APPDATA%\ClaudeLauncher\launcher.log`: the shell used, the exact `wt.exe` command, and any error.

### Install

Download `ClaudeLauncher-win-Setup.exe` below and run it. Installed copies update themselves on their next launch.

Needs Windows Terminal and Claude Code (`claude`) installed.
